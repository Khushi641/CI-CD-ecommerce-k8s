# E-Commerce CI/CD on Kubernetes

## Tech Stack
Docker, Kubernetes, Jenkins, AWS EKS, Git, GitHub

## Project Summary
End-to-end CI/CD pipeline for deploying an e-commerce web application on Kubernetes.

### What I Implemented
1. Dockerized the web application using Dockerfile
2. Deployed on AWS EKS with Kubernetes deployments and services
3. Built automated Jenkins pipeline for Build, Push, Deploy
4. Configured rolling updates for zero downtime deployment

## Key Learnings
Containerization, Kubernetes Orchestration, CI/CD Automation, Cloud Deployment
